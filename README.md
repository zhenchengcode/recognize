# 打钩记录 PWA

功能：
- 输入文字，回车生成标签
- 标签可以无限次打钩
- 自动记录每次打钩时间
- 显示总次数、最近一次时间和完整历史
- 数据保存在浏览器 localStorage
- 支持 PWA / 离线缓存

部署：
把整个文件夹上传到任意 HTTPS 静态网站服务即可，例如 Vercel / Netlify / Cloudflare Pages / GitHub Pages。

iPhone：
1. 用 Safari 打开部署后的网址
2. 点击分享
3. 选择“添加到主屏幕”
